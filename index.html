Gazipur Mobile Hub POS

POS system-এর ওয়েবসাইটের entry page তৈরি করা হয়েছে।

গুরুত্বপূর্ণ: শুধু GitHub Pages-এ frontend দেখানো যায়; বিক্রি save, barcode lookup ও invoice-এর জন্য Node.js backend এবং Supabase চালু থাকা দরকার। Backend deploy না থাকলে POS-এর API কাজ করবে না।
POS frontend preview GitHub repository

পূর্ণ POS চালু করতে backend-টি Node.js hosting-এ deploy করে সেখানে SUPABASE_URL ও SUPABASE_ANON_KEY environment variables সেট করতে হবে। এরপর সেই backend URL-এই POS ব্যবহার করতে হবে।
